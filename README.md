# 📱 QR Code Generator

A modern and responsive **QR Code Generator** built with **HTML, CSS, and JavaScript**. Generate QR codes instantly from text or URLs, customize their size and error correction level, download them as PNG images, and switch between light and dark mode.

## ✨ Features

- 🔗 Generate QR codes from text or URLs
- 📏 Multiple QR code sizes
- 🛡️ Adjustable error correction levels
- 💾 Download QR codes as PNG
- 📋 Copy text to clipboard
- 📋 Paste text from clipboard
- 🗑️ Clear input and generated QR codes
- 🔢 Live character counter
- 🌙 Light/Dark mode
- 💾 Saves theme preference
- ⌨️ `Ctrl + Enter` keyboard shortcut
- 📱 Responsive design
- ✅ Input validation
- ⚡ Instant QR code generation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js
- Clipboard API
- LocalStorage
